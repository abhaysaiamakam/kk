# KeenKeep

Isolated copy of the KeenKeep patient and caregiver application. The Firebase configuration in this repository targets the dedicated `keenkeep-live-2026` project; the original `nationpro99-lgtm/KeenKeep` repository and its Firebase project are not modified.

The remaining Firebase console setup must be completed before live database access works. See the project configuration files for the selected Firestore region and security rules.
